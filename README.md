# nLuck — карточный клуб в Telegram

Telegram Mini App с пятью карточными играми, матчмейкингом, столами для друзей, ботами, балансом монет и профилем.

## Игры

| Игра | Игроки | Суть |
|---|---|---|
| **108** | 2–6 | Сбрось карты первым и не набери больше 108 очков (свои правила: перевод 6/7, 8 надо покрыть, туз — пропуск, K♠ +4, дама в любой момент) |
| **Дурак** | 2–6 | Подкидной, 36 карт, по 6, козырь под колодой |
| **Бура** | 2–4 | Взятки 1–3 картами одной масти, первым набери 31 |
| **Покер** | 2–6 | Техасский холдем до последнего, 1000 фишек, блайнды растут |
| **Блэкджек** | 1–5 | Против дилера на монеты, дилер добирает до 17 |

## Клуб

- Главная: карусель игр, «Играть» (матчмейкинг), «С друзьями» (стол по коду), «С ботами».
- Матчмейкинг по режимам каждой игры со счётчиками «играют / ищут».
- **Монеты** (игровые, не деньги): старт 1000, ежедневный бонус +300. Ставка в матчмейкинге (108/Дурак/Бура — 50, Покер — 200) идёт в банк, победители его делят. С ботами и друзьями — на интерес.
- **Профиль**: уровень и опыт, баланс, статистика по каждой игре. Хранится в SQLite (`DATA_DIR`, на Railway — диск `/data`).
- Достижения по каждой игре, настройки (звук, вибрация, подсказки, лайт-версия, рубашки).
- Чат: общий в клубе и за столом (текст + эмодзи), приглашение друзей ссылкой `t.me/<бот>?start=r_КОД`, зрители за идущим столом.

## Запуск

```bash
npm install
npm start      # http://localhost:3000 — без BOT_TOKEN можно зайти гостем
npm test
```

Переменные: `BOT_TOKEN`, `WEBAPP_URL`, `DATA_DIR` (папка базы), `APP_SHORT_NAME` (необязательно).

## Структура

```
src/
  server.js, lobby.js   HTTP/WebSocket, матчмейкинг, комнаты, ставки
  db.js                 профили, монеты, статистика (node:sqlite)
  bot.js                бот: одна кнопка «Открыть nLuck»
  game/                 движок «108»
  games/                Дурак, Бура, Покер (+оценка рук), Блэкджек, реестр игр
public/
  app.js                главная, профиль, матчмейкинг, стол «108»
  table.js              столы Дурака, Буры, Покера, Блэкджека
  games-info.js         описания и правила игр
  cards.js              SVG-карты (36 и 52)
```
