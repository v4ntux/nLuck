# 108 — карточная игра для Telegram (Web App)

Мини-приложение Telegram: игра «108» на 36 карт с матчмейкингом, столами для друзей и ботами.

## Возможности

- **Начать игру**: матчмейкинг на 2, 3 или 4 игрока. Если соперники долго не находятся, через 10 секунд появляется кнопка «Начать с ботами».
- **Играть с друзьями**: стол с кодом из 5 символов. Приглашение уходит через Telegram, друг заходит по ссылке сразу за стол. Можно позвать до 6 игроков и добавить ботов.
- **Тренировка**: игра против 1–3 ботов.
- Карты нарисованы векторно (SVG), с картинками на вальтах, дамах и королях.
- Анимации, вибрация (Telegram Haptics), таймер хода 30 секунд. Если время вышло или игрок отключился, за него ходит бот.
- Можно переподключиться к игре после обрыва связи.
- Вход проверяется через подпись Telegram `initData`.

## Правила

| Карта | Эффект |
|---|---|
| **6** | следующий берёт 1 карту и пропускает ход |
| **7** | следующий берёт 2 карты и пропускает ход |
| **Туз** | следующий пропускает ход |
| **Дама** | кладётся на любую карту, заказывает масть |
| **9, 10** | обычные карты: 9 стоит 9 очков, 10 — 10 очков |

Очки за карты на руке в конце раунда: 6–10 по номиналу, валет 2, король 4, туз 11,
**дама +20, дама♠ +40, король♠ +80**. Закончил раунд дамой — **−20**, дамой♠ — **−40**, королём♠ — **−80**.
Очки копятся по раундам и могут уходить в минус. Больше 108 — вылет, ровно 107 — счёт делится пополам, ровно 108 — обнуляется. Побеждает последний оставшийся.

Все правила собраны в `src/game/rules.js`, их можно менять там.

## Запуск локально

```bash
npm install
npm start            # http://localhost:3000 — без BOT_TOKEN можно играть как гость в браузере
npm test
```

## Подключение к Telegram

1. Создай бота в [@BotFather](https://t.me/BotFather) и возьми токен.
2. Задеплой сервер на любой хостинг с HTTPS и WebSocket (Railway, Render, Fly.io, VPS с Docker).
3. Задай переменные окружения (см. `.env.example`):
   - `BOT_TOKEN` — токен бота
   - `WEBAPP_URL` — публичный HTTPS-адрес сервера
   - `APP_SHORT_NAME` (необязательно) — короткое имя Mini App из BotFather `/newapp`. С ним приглашения открывают игру сразу: `t.me/<бот>/<app>?startapp=КОД`
   - `ALLOW_GUESTS=0` — запретить вход без Telegram
4. Напиши боту `/start`. Он ответит кнопкой «Играть», а ещё поставит кнопку меню.

```bash
docker build -t karta108 . && docker run -p 3000:3000 --env-file .env karta108
```

## Структура

```
src/
  server.js      HTTP + WebSocket сервер
  lobby.js       матчмейкинг, комнаты, таймеры, боты
  bot.js         Telegram-бот (grammy)
  auth.js        проверка initData
  game/
    rules.js     правила и очки
    engine.js    логика партии (сервер решает всё)
    ai.js        бот-соперник
public/          клиент Web App (без сборки)
  index.html, styles.css, app.js, cards.js (SVG-карты)
test/            тесты движка и авторизации
```

> Состояние игр хранится в памяти процесса. Для одного сервера этого достаточно; при перезапуске идущие партии сбрасываются.
