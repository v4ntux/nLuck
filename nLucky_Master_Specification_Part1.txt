nLucky Telegram Bot - Master Specification (Part 1)

Goal

Create a premium Telegram casino/economy bot named nLucky using Aiogram
3.x, PostgreSQL and Redis. The bot must work in groups and private
chats. Every interaction uses inline keyboards and message editing
instead of sending many new messages.

Core Features

-   Virtual currency only (no real money).
-   Economy shared across all games.
-   Beautiful dark-purple UI matching nProject branding.
-   Fast callback-based UX.
-   Modular architecture.
-   Admin panel.
-   Anti-spam / anti-cheat.
-   Statistics, leaderboards, achievements.

Each game must define: - entry flow - validation - bet limits - payout

Admin Panel

/admin

Permissions: - Owner - Admin - Moderator

Functions: - add/remove balance - reset profile - ban/unban - mute
games - create promocodes - edit economy - broadcast - view logs - edit
missions - edit daily rewards - edit shop - reload config - maintenance

UI Style

Dark background. Purple neon. Rounded buttons. One edited message
whenever possible.

Development Rule

Never hardcode values. Everything configurable through config files.

The remaining specification (menus, every game algorithm, callback map,
FSM, Redis keys, anti-cheat, scheduler, admin UX) should continue in
subsequent documents.

## Что сделает бота залипательным

* ⚡ Все игры работают через **inline-кнопки**, без постоянного ввода команд.
* ⚡ Одно сообщение редактируется, а не создаются десятки новых.
* ⚡ Поддержка как **одиночных игр**, так и **PvP** и **массовых режимов** (Jackpot, Battle Royale, Race).
* ⚡ Общий профиль, валюта, уровни и достижения для всех игр.
* ⚡ Случайные ежедневные события (Rain, Happy Hour с повышенными выплатами, двойной XP).
* ⚡ Красивые анимации через последовательное редактирование сообщения (`🎲`, `🎰`, `💥`) создают ощущение живого казино.

Если делать такой проект на **Aiogram 3.x**, с нормальной архитектурой (FSM, Redis для игровых сессий, PostgreSQL для экономики), получится полноценная игровая экосистема для Telegram-групп, а не просто набор команд.
